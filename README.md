# 典型场景代码

本仓库保存四个典型场景的开发前原始代码，尚未接入首页待办角标汇总功能。

## 目录结构

- 典型场景/低压业扩报装
- 典型场景/配网检修
- 典型场景/配网抢修
- 典型场景/配网巡视

每个模块以 index.html 为入口，保留原有 js、css 和 images 资源。

## 使用说明

这些页面用于一平台后台工具管理的场景资源包，依赖部署环境中的 /a_js/ 公共脚本、业务系统登录态和 BrowserAction 客户端能力，不能保证直接双击 HTML 即可完整运行。

上传后台时应分别打包各模块，保持原模块内部目录结构。仓库保存解压后的源码，不重复存储现有 ZIP 文件。
